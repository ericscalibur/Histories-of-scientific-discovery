# Media sourcing notes

Policy for this project: **photographs of real historical objects and period artwork
only** — museum artifacts, period engravings and woodcuts, original book plates. No
AI-generated imagery, no modern reconstructions presented as period work, and no
mislabeled images (every caption is verified against the artwork itself).

All artwork used is old enough to be public domain as *artwork*. Two practical notes
for redistribution:

1. **Prefer Wikimedia Commons scans.** Some working copies used during development
   came from stock-photo archives whose scans carry watermarks (e.g., the Tycho nova
   map currently embedded in the Tycho lesson is an archive-watermarked scan, noted
   honestly in its caption). Faithful reproductions of public-domain 2D works are
   generally not independently copyrightable (Bridgeman v. Corel), but clean,
   unencumbered scans of every image used here exist on Wikimedia Commons — swap them
   in before wide redistribution.
2. **Images are embedded, not linked.** Lessons embed images as data URLs so each HTML
   file stays fully self-contained and offline-capable. To replace an image, re-embed
   it (the source scripts show the pattern) rather than adding external links.
